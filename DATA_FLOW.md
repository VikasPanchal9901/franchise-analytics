Data Flow — FranchiseOps
1. Data Sources
Sales transactions (outlet, product, quantity, amount, time)
Customer reviews and ratings
Staff records (attendance, shifts, productivity)
Marketing campaign data
Audit and compliance checks
2. Central Storage

All of the above is stored in one place, organized by outlet, product, and date — so every module is working from the same underlying data, not separate copies.

3. Processing

Raw records are turned into meaningful numbers before they reach a dashboard:

Sales are totaled into daily/monthly revenue, growth, and margin
Stock levels are compared against reorder points to flag shortages
Review text is analyzed to detect positive/negative sentiment
Transaction patterns are checked against simple rules to flag compliance issues (e.g. unusual discount activity, low ratings, repeated stock-outs)
4. Dashboards

Each business function has its own dashboard, showing only what's relevant to it: Outlets, Inventory, Staff, Marketing, Sales, Audit, Notifications, and an Executive overview that summarizes all of them together.

5. Real-Time Updates

New sales and alerts appear on the dashboard as soon as they happen, without needing to refresh the page.

6. User Actions Feed Back In

When a user acknowledges or resolves an alert, that action is saved immediately and reflected everywhere it's shown — closing the loop.

Flow at a Glance

Data Sources → Central Storage → Processing → Dashboards → User Actions → back to Storage
